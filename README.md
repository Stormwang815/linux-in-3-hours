## 📖 项目简介

随着人工智能与云服务器的普及，越来越多非计算机背景的学习者与开发者需要上手 Linux。市面上的教程往往走向两个极端：要么是动辄几十小时的教科书式长篇大论，要么是零碎残缺的命令罗列。

**《3小时速通Linux》** 坚持 **「最小但够用、边读边敲」** 的理念，将高口碑教程 [《只学够用的 Linux：零基础最小入门教程》](https://www.zouht.com/4399.html) 及其两篇高价值延伸精讲（`tmux` 终端复用器、`CUDA` 多版本切换）**深度精修、重排并一体化离线打包**：

- **彻底脱离服务器与网络**：不依赖任何 CDN、后端或环境安装，双击 `.html` 即可在电脑、手机、iPad 随时随地流畅查阅。
- **边读边敲，零风险实操**：内置纯前端虚拟 Linux 命令模拟器与 **12 个章节联动闯关练习**，再也不怕新手把真电脑 `rm -rf` 搞崩。
- **全量图文动图瘦身优化**：45 组图解与终端演示全部本地化（超大 GIF 已转高清可暂停 MP4，总资源压缩 61%，单文件便携版仅 **9.65 MB**）。

## 💻 内置交互式 Linux 命令模拟器

内置纯内存虚拟文件系统（VFS）与 Bash 仿真解析器，真实支持 **30+ 核心命令**、**管道 `|`**、**输出重定向 `>` / `>>`**、**命令连接 `&&` / `;`**、**通配符 `*`**、**环境变量 `$VAR`**、**真实虚拟 `tar` 打包/解压** 与 **`rm -rf /` 安全警示拦截**。

### 12 个精选实战闯关关卡

| 关卡 | 对应章节 | 实战任务 |
| :---: | :---: | :--- |
| **L1** | `1.3.5` | 使用 `mkdir -p` 递归创建多级目录并用 `touch` 新建文件 |
| **L2** | `1.3.6` | 使用 `find . -name "*.log"` 递归查找日志文件 |
| **L3** | `1.4.2` | 复制配置文件 `demo.conf` 到 `backup/` 目录并重命名 |
| **L4** | `1.5.3` | 区分并安全删除空目录（`rmdir`）与非空目录（`rm -r`） |
| **L5** | `1.8.2` | 体验 `touch /etc/my_app.conf` 权限拒绝，再用 **`sudo !!`** 一键提权重试 |
| **L6** | `1.7.3` | 组合 `grep`、管道 `\|`、`wc -l` 与重定向 `>` 统计错误日志行数 |
| **L7** | `1.8.4` | 使用 `chmod 755`（或 `+x`）为脚本赋予执行权并运行 `./run.sh` |
| **L8** | `2.3.2` | 使用 `grep -rn` 递归检索整个日志目录并显示行号 |
| **L9** | `2.2.1` | 使用 **`tar -czvf`** 打包压缩目录，再用 **`tar -xzvf ... -C`** 解压到目标目录 |
| **L10** | `2.4.1` | 复现磁盘扩容经典案例：`mv` 迁移数据目录 + `ln -s` 创建软链接 |
| **L11** | `2.8.1` | 使用 `export` 导出环境变量并用 `echo $VAR` 读取验证 |
| **L12** | `2.6.5` | 服务器日常排障：组合 `df -h` 查磁盘空间与 `nvidia-smi` 查 GPU 显存 |

> 除闯关模式外，还可随时一键切换至 **「自由沙盒模式」**，自由敲命令探索预置的 Linux 目录树，随时点击「重置环境」一键复原。

## ❓ 常见问题

**Q：打开 `index.html` 需要安装 Node.js 或启动本地 Web 服务器吗？**  
不需要。所有样式、脚本、搜索索引与媒体资源均已纯本地化，直接用任意现代浏览器（Chrome / Edge / Safari / Firefox）双击 `index.html` 即可完整运行（含代码一键复制、打卡保存、交互终端与全部动图）。

**Q：标准版和单文件便携版有什么区别？**  
两者**内容与功能 100% 完全一致**。电脑端日常使用推荐根目录的 `index.html`（网页本体仅 648 KB，图片按需懒加载，秒开省内存）；如果要通过微信、AirDrop、U 盘发给朋友或在手机/平板上离线打开，直接传 `dist/3小时速通Linux-完整单文件离线版.html` 这 1 个文件最省心。
